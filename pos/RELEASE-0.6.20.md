# POS 0.6.20 — Android printing compatibility

ผู้ใช้ Android/Huawei รายงานว่า 0.6.19 แสดงว่าส่งข้อมูลแล้ว แต่กระดาษไม่ออก ยังไม่มีแท็บเล็ตเชื่อมกับเครื่องพัฒนา จึงยังยืนยันสาเหตุกับฮาร์ดแวร์จริงไม่ได้

- คืนการแบ่งภาพ raster บน Android เป็นรูปแบบ 0.6.18 ที่รวมช่วงภาพมีหมึกต่อเนื่อง แทนการแบ่งเป็นชิ้นเล็กแบบ 0.6.19 เพื่อทดสอบความเข้ากันได้กับ firmware เครื่องพิมพ์
- คงใบเสร็จไม่มีบาร์โค้ด และตัวเลือกเปิด/ปิด QR จาก 0.6.19
- เพิ่ม “ทดสอบข้อความพื้นฐาน (ไม่ใช้ภาพ)” ส่ง ASCII ESC/POS โดยตรง แยกการเชื่อมต่อ/สถานะเครื่องออกจากการเรนเดอร์ภาพ และไม่เปิดลิ้นชัก
- เปลี่ยนข้อความสำเร็จเป็น “ส่งข้อมูล Bluetooth ครบแล้ว กรุณาตรวจว่ามีกระดาษออกจริง” เพราะ Bluetooth ACK ไม่ได้ยืนยันว่าพิมพ์กระดาษสำเร็จ
- คงการตรวจสิทธิ์และ audit ก่อนเขียนข้อมูล ไม่มีการพิมพ์ซ้ำอัตโนมัติ
- Android versionCode 27 ลงทับรุ่นเดิมด้วย signing key เดิม

## ผลตรวจ

- POS tests 18 รายการ รวมทดสอบข้อความโดยไม่ผ่าน image renderer และไม่เปิดลิ้นชัก
- Java raster tests ตรวจ framing 0.6.18 และความถูกต้องของจุดพิมพ์/ความสูง
- Android bridge และการแบ่ง BLE packets ผ่าน

## ทดสอบที่เครื่องร้าน

1. ปิดแอปและปิด/เปิดเครื่องพิมพ์ เพื่อล้างข้อมูลงานพิมพ์ค้าง
2. ติดตั้ง `pos/release/8-Sian-POS-Huawei-0.6.20.apk` ทับ แล้วค้นหา/เชื่อมต่อเครื่องพิมพ์
3. กด “ทดสอบข้อความพื้นฐาน (ไม่ใช้ภาพ)” ควรมีกระดาษคำว่า `8 SIAN POS` และ `BASIC PRINTER TEST`
4. กด “พิมพ์ทดสอบภาษาไทย” เพื่อทดสอบเส้นทางภาพ

ถ้าข้อความพื้นฐานออกแต่ภาษาไทยไม่ออก ให้ตรวจเส้นทางภาพต่อ ถ้าข้อความพื้นฐานไม่ออกด้วย ต้องตรวจสถานะกระดาษ/ฝาครอบ เครื่องที่เลือก และโปรไฟล์การเชื่อมต่อเพิ่มเติม ยังไม่ถือว่าพิมพ์สำเร็จเพียงเพราะขึ้นว่าส่งข้อมูลครบ
