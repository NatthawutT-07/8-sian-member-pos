# POS Android 0.6.25

ใช้ไฟล์ `8-Sian-POS-Android-0.6.25.apk` เดียวกันสำหรับ Samsung/Huawei ที่รองรับ Android APK ใช้ application ID และกุญแจเซ็นเดิม ติดตั้งทับรุ่นเดิมโดยไม่ต้องถอนแอป

- ออเดอร์ครัวเรียงหนึ่งแถว เลื่อนแนวนอนเพื่อดูออเดอร์ถัดไป รองรับแนวตั้ง/แนวนอน
- ลดความกว้างการ์ดเป็น 300 พิกเซล ลดช่องว่างเป็น 8 พิกเซล ปรับตัวอักษรและพื้นที่รายการให้กระชับ โดยคงปุ่มสัมผัสอย่างน้อย 44 พิกเซลบนแท็บเล็ต
- หน้าเว็บเชฟและตัวเปิดพิมพ์ Windows ใช้ใบเลขโต๊ะขนาด 80 × 30 มม. สำหรับ ES-9910UB และใบทดสอบแสดงเฉพาะ “โต๊ะ 3”
- รวมชำระเงินสด+โอนและนับเงินเปิดกะจาก 0.6.24

ไม่มี backend หรือ migration เพิ่มจาก 0.6.24 แต่ backend ต้องมี migration `202611180001_pos_mixed_payment` อยู่แล้วก่อนใช้การชำระแบบผสม

หน้าเว็บ `/chef` ต้อง deploy frontend ใหม่ ส่วนหน้าครัวในแอป Android รวมอยู่ใน APK นี้แล้ว การตั้งค่าไดรเวอร์ ES-9910UB ขนาด `80*30` เป็นการตั้งค่าที่ Windows แต่ละเครื่อง ไม่ได้ติดตั้งไปพร้อม APK และไม่ได้เพิ่มความสามารถ Bluetooth สำหรับเครื่องพิมพ์รุ่นนี้บน Android
