# POS 0.6.23

- หน้าโต๊ะ / ออเดอร์อาหารแสดงเวลาเริ่มรอบโต๊ะ เวลาสิ้นสุดสั่งอาหาร และเวลาคงเหลือ HH:MM:SS
- นับถอยหลังบนเครื่องทุกวินาที ไม่เรียก API เพิ่มทุกวินาที การดึงสถานะล่าสุดยังใช้รอบเดิม 15 วินาทีขณะเปิดหน้าต่าง
- หมดเวลาแสดง 00:00:00 เปลี่ยนโต๊ะเป็นสีเหลืองพร้อมข้อความ “หมดเวลา • รอปิดโต๊ะ” และปิดปุ่ม QR
- Backend เดิมตรวจ deadline ทุกครั้งก่อนรับออเดอร์อยู่แล้ว ลูกค้าใช้ QR หมดอายุสั่งต่อไม่ได้ แม้ยังเปิดหน้าเว็บค้างไว้
- หมดเวลาไม่ปิดโต๊ะ ไม่ทำให้โต๊ะว่าง ไม่ยกเลิกอาหารที่รับไปแล้ว พนักงานต้องกดปิดโต๊ะใน POS เอง
- เวลาเริ่มรอบอ้างอิง openedAt ส่วนเวลาสิ้นสุดอ้างอิง qrExpiresAt ของรอบปัจจุบัน โต๊ะรอเลือกโซนแสดง “ยังไม่เริ่ม”

ไม่มี schema migration หรือ backend API ใหม่ ต้องใช้ backend ที่รองรับ QR รายรอบและ checkout ของ POS 0.6.22 อยู่แล้ว ติดตั้ง Android/Huawei 0.6.23 ทับรุ่นเดิม
