# POS 0.6.22

- เลือกโซนอาหาร เช่น หมูกระทะ / ทะเล จากโซนในหลังบ้าน ก่อนเลือกเงินสดหรือโอนเงิน เลือกได้หลายโซน
- บันทึกการชำระเงินและสิทธิ์สั่งอาหารใน transaction เดียวกัน QR เริ่มนับอายุเมื่อชำระสำเร็จ ไม่ต้องยืนยันโซนซ้ำ
- ติ๊กพิมพ์ QR สั่งอาหารท้ายใบเสร็จก่อนชำระเงิน พิมพ์รวมแผ่นเดียว ไม่พิมพ์ใบ QR แยกอัตโนมัติ ไม่เลือกโต๊ะจะไม่มี QR
- โซนและตัวเลือก QR ของบิลที่ส่งแล้วถูกเก็บสำหรับ retry โดยไม่คิดเงินหรือเปิดรอบโต๊ะซ้ำ
- ออเดอร์หน้าครัวเรียงเก่าไปใหม่เป็นแถวเดียว เลื่อนแนวนอน และคงตำแหน่งเลื่อนเมื่ออัปเดต
- แถบหมวดหมู่บนเว็บลูกค้าเลื่อนแนวนอนทุกขนาดจอ และยังติดด้านบนขณะเลื่อนรายการอาหาร
- ลบส่วนสร้างภาพ แสดง และดาวน์โหลด QR โต๊ะในเว็บแอดมิน ใช้ QR บนใบเสร็จจาก POS โดยยังตั้งอายุ QR และเพิ่มโต๊ะในแอดมินได้

ต้องอัปเดต backend ก่อนติดตั้ง POS รุ่นนี้ เพราะ checkout เพิ่มข้อมูลโซนและอายุ QR ไม่มี migration เพิ่มจาก 0.6.21 (หากยังไม่เคยอัปเดต 0.6.21 ต้อง apply migration QR รายรอบก่อน)

อัปเดต backend: สำรองฐานข้อมูล ตรวจ .env production แล้ว `git pull --ff-only origin main` จากนั้น `pm2 stop 8sian-backend && npm ci && npm run generate && npm run migrate && pm2 restart 8sian-backend --update-env`

Deploy frontend ที่ https://8sianracha.com และติดตั้ง Android/Huawei 0.6.22 ทับรุ่นเดิม

ปุ่มดู / พิมพ์ QR แยกในหน้าโต๊ะยังใช้ได้สำหรับกรณีพนักงานขอพิมพ์เพิ่มเอง
