# POS Android 0.6.24

ไฟล์ติดตั้ง `8-Sian-POS-Android-0.6.24.apk` ใช้ไฟล์เดียวกันสำหรับ Samsung และ Huawei ที่รองรับ Android APK (Android API 26 ขึ้นไป ไม่รองรับ HarmonyOS NEXT) ใช้ application ID และ signing key เดิม ติดตั้งทับ 0.6.23 ได้โดยไม่ต้องถอนแอป

- ชำระเงินสดร่วมกับเงินโอน คำนวณเงินทอนและแสดงยอดแยกบนใบเสร็จ
- เปิดกะด้วยการนับจำนวนเงินชนิด 1,000 / 500 / 100 / 50 / 10 / 5 / 2 / 1 บาท
- ปุ่มสัมผัสและกริดออเดอร์ครัวสำหรับแท็บเล็ตขนาดเล็ก เช่น Samsung Tab A7 Lite ทั้งแนวตั้งและแนวนอน
- พิมพ์ครัวเฉพาะเลขโต๊ะตัวใหญ่ผ่านระบบภาพเดียวกับใบเสร็จ POS

ต้องอัปเดต backend พร้อม migration `202611180001_pos_mixed_payment` ก่อนใช้งานชำระผสม ดู [ขั้นตอนอัปเดต server](../docs/UPDATE-SERVER-2026-11-18.md)

อัปเดตหน้าเว็บ `/chef` แยกผ่าน frontend ส่วนหน้าครัวในแอป Android รวมมากับ APK นี้แล้ว ต้องตรวจการติดตั้ง การจัดหน้า และเครื่องพิมพ์ Bluetooth บนอุปกรณ์จริงก่อนใช้งานหน้าร้าน

ตรวจ APK แล้ว: versionCode 31, versionName 0.6.24, ลายเซ็นตรงกับ APK Huawei 0.6.23 และบรรจุไฟล์ UI/พิมพ์ล่าสุด ตรวจ Android bridge และ BLE ผ่าน
