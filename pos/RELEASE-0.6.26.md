# POS Android 0.6.26

แก้หน้าคิดเงินค้างหลังเซสชันหมดอายุ และบิลค้างที่กลับมาล็อกเครื่องแม้ปิดเปิดแอปใหม่ ใช้ APK เดียวกันสำหรับ Samsung/Huawei ที่รองรับ Android APK ติดตั้งทับด้วยกุญแจเซ็นเดิม ไม่ต้องถอนแอป

- Backend เพิ่มอายุการเข้าสู่ POS เป็น 24 ชั่วโมงต่อการเข้าสู่ระบบ (ไม่เปลี่ยนอายุ session แอดมิน)
- เมื่อได้ 401 หรือครบเวลาที่ backend แจ้ง กลับหน้าเข้าสู่ระบบ ล้างตะกร้า สมาชิก คูปอง ยอดรับเงิน และสถานะกำลังทำงาน ตรวจ session ทุก 60 วินาทีและเมื่อกลับมาเปิดแอป
- ปุ่ม **ล้างตะกร้า / เข้าสู่ระบบใหม่** ช่วยออกจากสถานะค้างโดยคงข้อมูลตั้งค่าเครื่องพิมพ์ไว้
- บิลส่งชำระแต่ไม่ทราบผลย้ายเข้า **บิลรอตรวจ** ไม่กลับมาล็อกตะกร้าหลังเปิดแอปใหม่ เข้าบัญชีพนักงานเดิมเพื่อตรวจผล ยืนยันด้วยรหัสบิลเดิม หรือยกเลิกคำขอที่ยังไม่สำเร็จ บิลที่ชำระสำเร็จไม่ถูกลบ
- ยกเลิกคำขอผ่าน backend ภายใน transaction ที่ล็อกกะร่วมกับ checkout และบันทึก audit ป้องกันคำขอเก่าที่มาถึงช้ากลับมารับชำระหลังยกเลิก
- จำกัดเวลารอ API/native bridge และละทิ้งคำตอบของ session เดิมหลังเข้าสู่ระบบใหม่
- รวมแถบนับธนบัตร/เหรียญตอนเปิดและปิดกะครบ 1,000 / 500 / 100 / 50 / 20 / 10 / 5 / 2 / 1 บาท และเสียงออเดอร์ใหม่ในหน้าครัว

**ต้อง deploy backend ที่มี `POST /api/pos/checkout/recover` ก่อนติดตั้ง APK นี้** ไม่มี schema หรือ migration ใหม่จากการแก้ session/recovery แต่ migration เงินสด+โอนเดิมต้องลงไว้แล้ว Session ที่สร้างก่อนอัปเดตจะคงเวลาหมดอายุเดิมจนเข้าสู่ระบบใหม่
