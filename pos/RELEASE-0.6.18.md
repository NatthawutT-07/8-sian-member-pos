# POS 0.6.18

- ปรับหน้าต่างเลือกโซนก่อนเปิดโต๊ะให้กระชับ พร้อมสถานะชำระเงินและจำนวนโซนที่เลือก
- โซนที่เลือกแสดงพื้นสีเขียว จัดสองคอลัมน์บนจอใหญ่และหนึ่งคอลัมน์บนจอเล็ก
- จัดปุ่มเลือกภายหลังและยืนยันเปิดโต๊ะในแถวเดียวกัน พร้อมคำอธิบายเมื่อยังไม่เลือกโซน
- คงการเลือกหลายโซน เปิดโต๊ะโดยไม่เลือกโซน และเลือกภายหลังตามเดิม
- Android versionCode 25 ใช้ signing key เดิมสำหรับติดตั้งทับ

ไฟล์ติดตั้ง:

- `pos/release/8-Sian-POS-Huawei-0.6.18.apk`
- `pos/release/8 Sian POS Setup 0.6.18.exe`

ตรวจ POS tests 15 รายการ, Android bridge/BLE และทดสอบ UI เลือกหลายโซน/ไม่เลือกโซน/เลือกภายหลังด้วยข้อมูลจำลองแล้ว ยังไม่ได้ทดสอบบนอุปกรณ์จริง
